## 实现状态

设置中心的全部分类共用同一个 Kit `Settings`：分类搜索、选中状态、侧栏尺寸和拖拽宽度由同一份内部状态管理。AI 不再组装独立侧栏，右侧通过 Normal 变体的 `SettingGroup` 嵌入自定义主体，避免 Outline 变体内层的固定边框与内距；其余分类保持 Outline。主体高度扣除共同顶栏、底部内距与 Kit 组间距，页签内容在有界 flex 容器中滚动和裁切，保存栏保持可见。Skill、MCP 和运行环境的数据操作与既有权限和确认行为不变。

AI 页按钮通过 `src/ui/components.rs` 的 `settings_command_button` 统一使用应用语义色：正文 12px、常规高度 32px、圆角 6px；“更多”高度 28px 并带弱描边。标签自行指定字号，避免 Kit 内部 `text_sm` 覆盖。已就绪、已安装等状态使用带图标的浅色徽标，属于静态状态而非按钮。

## 入口与状态

- 保留设置中心左侧的「AI 设置」分类。在右侧现有 AI 连接配置中增加「Skill」「MCP」「运行环境」页签。
- 「启用 AI 功能」是三页的前置条件。关闭时页签保留但不可进入，显示启用说明；打开开关并保存后可配置。
- 页面底部固定「保存设置」，未修改时禁用，只保存 AI 总开关和连接配置。Skill 导入、MCP 服务保存、运行组件下载各自明确完成状态，避免一个保存按钮同时承担安装操作。
- 关闭 AI 后保留已有扩展配置；再次启用后可继续管理。实现时需核对现有持久化语义。

## 列表形态

Skill 与 MCP 统一采用**紧凑单行列表**（Codex / ZCode 风格），不再用大卡片：单行承载
「左侧方形图标 + 名称 + 一行描述 + 右侧状态标签 + 更多操作」，行间 1px 分隔线。目的是
一屏内能看到更多条目、便于横向比较状态。

- **行高 72px**：图标 24px，无彩色底；名称使用正文 SemiBold，描述使用次要色并截断为一行。
- **文字状态**：Skill 用「已安装」；MCP 内置服务用「已就绪」，自定义服务用「已配置」；保存配置不表示持续在线，
  未连通时改用警告色。
- **行内操作收进「更多」菜单**（右侧文字按钮「更多」）：查看详情、编辑、移除。移除仍需确认对话框。
  不再在行右侧平铺多个按钮。
- **分区头部**给出总数摘要（`2 个已安装` / `1 个内置 · 2 个自定义`）与主动作按钮
  （Skill：`打开目录` + 主按钮 `导入 Skill`；MCP：`添加服务`）。
- MCP 的内置 `browser.edge` 与自定义服务**同列表展示**，靠描述里的「内置」前缀和图标区分，
  不再拆成「内置服务 / 自定义服务」两个分区。
- 列表与分区头部之间用 1px 顶线分隔，替代原先每个条目各自包一层卡片。

## 关键交互

1. **Skill**：选择包含 `SKILL.md` 的文件夹后先显示包名、说明和文件清单，再确认导入到应用数据目录的 `workflow-skills`。列表提供查看详情和移除入口；运行 Skill 时继续展示所需 MCP 工具并逐次授权。
2. **MCP**：内置 `browser.edge` 单独显示状态。自定义服务使用本地 stdio 命令与参数；新服务连接测试后默认启用发现的全部工具，可直接保存。「高级配置（可选）」默认收起，供关闭个别工具及调整读写提示；重新测试保留本次选择，编辑已保存服务保留原有白名单。未指定读写类型的工具按写入处理，工作流运行前仍确认本次使用的工具。表单内容使用有界滚动视口，底部取消与保存按钮固定，工具列表不能绘制到弹框外。
3. **Node / 浏览器 MCP**：先检测本机兼容 Node；缺少时仅在用户点击下载后将 Node 放入应用数据目录，再安装浏览器 MCP 依赖。下载阶段、失败原因、重试与最终 Node 来源应在同一页呈现。不要要求用户手工安装 `npm` 或 `npx`。
4. **状态反馈**：列表区分未安装、安装中、已就绪和失败。下载期间不显示虚构的百分比；进度条是阶段性示意，正式实现应按实际可获得的进度呈现。

## 与现有实现的衔接

设置中心统一由 `src/repository_ui.rs` 进入 Kit `Settings`，AI 分组由 `src/settings_center.rs` 接入 `src/ai_settings_page.rs`。Skill 读取 `workflow-skills`，MCP 使用 `workflow-mcp.json5`，内置 Edge 运行组件在 `src/workflow/browser_runtime.rs` 中按需安装。异步任务通过 `TaskExecutor` 与带请求代际的 `UiEvent` 回填；可视化保存 MCP 配置会将 JSON5 文件写成标准 JSON 格式。


## 2026-09-30 优化实现

- 连接页按标签、输入框和字段说明排版，API Key 显示本地明文存储提示，默认参数读取实际配置。显隐使用 Kit 原生按钮。
- 保存只影响总开关和连接配置；校验或写入失败时在保存栏展示原因，不弹成功通知。Skill 与 MCP 操作仍即时生效。
- 连接测试状态独立于全局 Git 操作。请求携带代际和参数快照；修改地址、密钥或模型后不展示旧配置的通过状态，迟到或重复事件不能结束新请求。异常与空响应按失败收尾。
- 运行环境使用无边框浅色区块，展示真实 Node 来源、版本、安装状态和阶段反馈，不显示虚构进度。
- Kit 0.6.4 的 Tab 渲染会覆盖调用方的底色、圆角和边框，无法呈现稿中的淡色选中块；页签复用 Kit Button，补充左右方向键、Home/End 与对应焦点切换。其余按钮、输入与开关仍使用 Kit。
- 字体沿用应用系统字体，颜色由现有主题 token 提供；没有改动 Kit 依赖版本。

实机截图发现的滚动内容覆盖保存栏问题，已通过有界 flex 外层、确定高度滚动视口和内容裁切修正；实际显示与键盘交互仍须以运行窗口验收。
