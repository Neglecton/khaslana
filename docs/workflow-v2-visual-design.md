## 2026-10-07 实机反馈修正

用户实机截图显示 Git 操作类型下拉触发器文字被裁掉，菜单列表未限制高度；步骤在摘要为空时仍保留第二行。V2 下拉触发器改用 Kit 原生 label，字段容器负责分配宽度；各选择菜单标记当前选项，较长列表启用有界滚动。步骤标题左对齐，只有实际摘要存在时才绘制第二行。

可用变量的输入、自定义变量、前序步骤输出和内置变量均提供复制图标，复制完整的 `${...}` 引用，并通过既有状态栏／通知提示成功。复制按钮按变量来源隔离交互 id。

## 原生行为

- 新建模板使用 V2 文档编辑器。V1 原格式和原向导保留，可点「以 V2 编辑副本」另存；不会就地迁移原件。
- 输入变量置于步骤上方；展开说明可编辑显示名称、描述、必填属性及自定义变量。
- 一次展开一个步骤；支持上移、下移、复制、删除。复制 invoke 生成新标识并清空输出名，避免覆盖原步骤输出。
- 添加步骤可搜索 Git 操作、MCP、JavaScript、Skill。MCP 服务与工具、已安装 Skill 可直接选用；JS 与 Skill 的允许工具使用受控菜单与可移除标签，完整列表保留高级 JSON5 入口。
- MCP 显示服务、工具及对象参数；JS 显示脚本、输入及工具；Skill 显示名称、任务及工具。高级配置保留步骤标识、动作名、额外参数和页面守卫。未知 invoke 完整保存 with 对象。
- 可用变量栏在窗口逻辑宽度至少 1100px 时显示在右侧，较窄时移至内容底部。输出仅列出当前步骤之前产生的变量。
- 「检查模板」校验结构、唯一步骤标识、保留输出名及外部动作参数；显示保存内容。此检查不执行 Git、MCP、JS 或 Skill。保存后回到运行页，沿用实际输入、执行预览、权限确认、取消及日志链路。
- V2 的 AI 生成使用 V2 输出约束，并提供可用扩展名称；回填继续校验编辑会话。V1 编辑不会接受 AI 返回的 V2 扩展动作。
- 输入复用 Kit 宿主与动态字段路由；单行 Enter 提交，脚本／任务／JSON 等多行 Enter 换行、Ctrl+Enter 提交。步骤搜索 Enter 加入匹配项，Esc 先退出选择器，再退出编辑器。
- 编辑页仍沿用模态焦点圈；按实际绘制边界拦截背景鼠标操作。AI 思考浮层使用原有顶层模态与收尾机制。

## 实现范围与验收

新增模块 `src/workflow_editor/document.rs`、`src/workflow_editor/v2.rs`、`src/workflow_editor/visual.rs`，通过既有编辑器和工作流页接入；未改变执行器权限、网络代理、Git 写入或后台调度边界。没有引入 DAG、循环、定时任务或新脚本运行器。

原生运行页复用现有输入／预览／日志组件，增加编辑入口及中文页面名。设计中的预览入口在原生编辑页呈现为「检查模板」，实际执行预览由保存后的运行页负责。

实机视觉验收仍未通过，详见 [design-qa.md](assets/workflow-v2/design-qa.md)。编译与自动化测试结果不能替代浅深主题、860×520、DPI、焦点和 IME 实机检查。

本次自动化验证：`cargo check --all-targets` 通过；`cargo test --lib --bin khaslana --quiet` 中库测试 575 项通过、7 项忽略，二进制测试 351 项通过，共 926 项通过；`cargo build --release` 使用默认 target/release，零错误、零编译警告；`git diff --check` 通过。新增 16 项 V2 编辑器回归测试，覆盖实际 Edge 示例、未知动作、嵌套参数、工具选择、复制与版本兼容。
